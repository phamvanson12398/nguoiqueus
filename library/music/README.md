# Nhạc nền cho video dài
Bỏ file nhạc **miễn phí bản quyền** (YouTube Audio Library, Pixabay Music, CC0; CC-BY thì ghi công trong mô tả video) vào đây:
`.wav` luôn đọc được; `.ogg/.flac/.mp3` đọc qua Blender. Trong story: `"music": [{"file": "ten_bai.mp3", "from": 1, "to": 900}]`.
Không có file thì tool tự tổng hợp nhạc theo `mood` (epic, tense, mystery, march, calm, sad, triumph), không vướng bản quyền.
