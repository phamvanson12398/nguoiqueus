# Tiếng động thật (thay cho tiếng tự tổng hợp)
Đặt file CC0 (ví dụ Freesound lọc giấy phép CC0, Sonniss GDC) tên đúng tên tiếng trong story: `sword_clash.wav`, `war_horn.wav`,
`march.wav`, `gallop.wav`, `arrows.wav`, `crowd_roar.wav`, `fire.wav`, `rain.wav`, `thunder.wav`… Có file thì tool dùng file, không thì tự tổng hợp.
Nền âm thanh dài: `amb_<loại>.wav` (amb_battlefield, amb_forest, amb_sea…) sẽ được lặp cho đủ thời lượng.
